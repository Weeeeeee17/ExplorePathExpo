# ExplorePath v0.9.1｜寵物故事與分頁順序更新測試版

和現實好友／家人／同事一起探索，在不知不覺中多走幾步。
保留個人探索、健康、好友組隊、足跡與 v0.9.0 養成規則；更新12篇蛋階段故事為使用者定稿。底部分頁依序為「探索 → 夥伴 → 好友 → 足跡 → 健康」。
尚未連線你的 Supabase 或通過雙手機實測，這不是已上線的多人服務。

## 最簡單的開啟方法

1. 先在舊版 App 匯出可用的 JSON 備份；在舊伺服器終端機按 Ctrl+C 停止。
2. 將 ExplorePath_v0.9.1_ExpoGo.zip 完整解壓縮到新的資料夾，不要覆蓋舊資料夾或直接在 ZIP 內執行。
3. 雙擊最外層 Start-ExplorePath.bat；啟動器會自動進入正確目錄。
4. 第一次執行 npm ci 安裝套件，等待完成並保留視窗。
5. iPhone 相機掃描新視窗的 QR，選擇 Expo Go。
6. 點「夥伴」查看新系統。首次成功一般探索才取得真實首蛋；也可從夥伴頁進入隔離展示沙盒先體驗。

需要 Node.js 22.13 以上（建議 Node 24 LTS，已安裝者不需重裝）、App Store 的 Expo Go（SDK 54），以及 iOS 15.1 以上。
本版沿用 v0.8.1 的 SDK54／React Native0.81.5／React19.1.0，不重新升級原生套件。
不需要 Apple Developer 付費會員、TestFlight 或每週重新簽署。

## 為什麼 v0.8 無法開啟

v0.8 的 SDK 57 與 iPhone App Store 版 Expo Go（SDK 54）不相容。終端機雖建議更新 App，單純更新 App Store 版並不能解決 SDK 57 的問題。
v0.8.1 對齊 SDK 54 全套原生套件，不只是修改顯示版本。啟動器檢查已安裝 SDK 與 lockfile，變更時重裝鎖定套件，並清除 Metro 快取。
參考：[Expo 官方版本不相容說明](https://docs.expo.dev/troubleshooting/expo-go-version-mismatch/)、[SDK 54 相容性表](https://docs.expo.dev/versions/v54.0.0/)。核對日期：2026-08-31。

若仍出現不相容提示，請確認掃描的是「新視窗」的 QR，且畫面標示 v0.9.1 / SDK54。不要刪除手機 Expo Go，以免遺失本機資料。相容性基線不等同這版已完成iPhone真機驗收。

- 寵物沙盒使用模擬資料；返回真實資料後不帶回示範步數、經驗或收藏。
- 圖片維持原稿，總計約53.3MiB，首次手機載入請稍候；沒有去背、重畫或製作3D。

## 手動啟動

若 PowerShell 位於解壓縮最外層，先執行：

```powershell
cd .\ExplorePathExpo
Test-Path .\package.json
npm ci
npm start -- --go --clear
```

Test-Path 必須回傳 True；若已在 ExplorePathExpo，不要重複 cd。cd 後必須有空格。
若回傳 False，不要接受 npx 安裝另一個 Expo 的提示，改用最外層啟動器。
兩端先連同一個可信任 Wi-Fi；LAN 不通先檢查私人網路防火牆及 Wi-Fi 隔離，不要關閉整個防火牆。本測試版不建議公開 tunnel。

## 本機預覽

能看好友分類、示範好友、夥伴／徽章、房間、倒數、任務與完成卡；不代表已連接其他手機。
預覽控制可增加示範步數，不會寫入真實健康紀錄。
真實好友邀請、限時 QR、復原、封鎖及跨手機定位必須接上同一個 Supabase 專案。

## 真正多人連線

依 SUPABASE_SETUP.md 設定 Free 專案、匿名登入、三份 migration、清理排程與 .env。已完成v0.9.0設定者無需新增SQL；僅完成v0.8者需新增第三份寵物展示SQL，不重建資料庫。好友雙方更新至v0.9.1才會看到相同新文案。
App 只需專案 URL 與 Publishable Key。
不要提供資料庫密碼、service_role、sb_secret 開頭的金鑰或私人復原密語。

## 重要限制

- 只同步前景定位，鎖屏與切 App 暫停，不宣稱背景持續定位。
- 30 秒是嘗試更新的頻率，不是即時服務保證。
- 撤回／封鎖阻止後續伺服器讀取，不能回收對方已收到或截圖的資料。
- 正常完成會刪除即時位置表的座標；期限清理每分鐘執行，讀取端另做期限檢查。供應商備份不是可保證立即抹除。
- 組隊步數先標示部分／至少；活動時間只估算前景有新增步數的時間片，不是 HealthKit 活動分鐘或醫療判定。
- 約略分享為 0.01 度網格，大小隨緯度改變，不是匿名化保證。
- 新寵物12蛋／8幼年已接入；成長、成熟與另4組幼年素材尚缺。僅顯示累積XP與實際階段，不新增數字等級。
- 沒有陌生配對、聊天室、排行榜、團隊累積步數或組隊推播。
- 照片不傳至 ExplorePath 雲端；分享到其他 App 後依該 App 行為處理。
- 社交復原不轉移照片或完整健康紀錄；一般 JSON 備份也不含相片與復原密語。
- 免費額度不足接受功能暫停，不升級、不加信用卡，不保證全民規模免費營運。
- SDK 54 工具相依仍有已知安全弱點；已套用相容的 PostCSS 修補，但不代表風險清零。只在可信任網路封閉測試，不公開 Metro、不處理不可信建置素材；詳見測試報告。

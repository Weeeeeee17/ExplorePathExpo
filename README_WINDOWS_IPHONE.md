# ExplorePath 真實感測版：Windows → iPhone

這一版可以只用 Windows 啟動，再用 iPhone 的 **Expo Go** 體驗真實前景定位、指南針、步數、附近地點搜尋、抵達判定、XP、寵物與足跡。不需要 Xcode、付費帳號、API 金鑰或信用卡。

## 第一版已完成的功能

- 真實模式預設開啟，只使用按下搜尋時的目前 GPS 位置。
- 選擇 20／40／60 分鐘與美食、自然、建築、隨機驚喜。
- 從 OpenStreetMap 公開資料搜尋附近地點；找不到時不會自行改條件。
- 半隱藏目的地、動態指南針、直線距離與不限次數換地點。
- GPS 誤差在 100 公尺內才判定抵達；動態範圍 40～100 公尺。
- 進入範圍累積停留 45 秒；短暫飄出 10 秒內不歸零。
- 抵達 100 XP；每 100 步加 1 XP，最多加 50 XP。
- 步數權限拒絕後仍可完成 GPS 探索，只是該趟步數加成為 0。
- 第一次完成探索會找到寵物蛋，之後探索推進孵化與成長。
- 真實的寵物、XP、足跡與進行中任務保存在 iPhone 本機。
- Demo 使用獨立暫存資料，完全不會改到真實進度。
- 可隨時「安全揭曉並開啟 Apple 地圖」，不扣 XP、不影響換點。

## 這一版刻意沒有做的事

- **沒有背景 GPS**：切到其他 App 或鎖定螢幕時，GPS、指南針與停留秒數暫停；回到前景後自動恢復，並嘗試從 iPhone 補回步數。
- **沒有上傳完整路線**：只在記憶體使用最新位置，不保存或上傳行走軌跡。
- **沒有雲端同步或帳號系統**：刪除 App／Expo Go 資料可能清除本機進度。
- **沒有路線導航 API**：時間以直線距離 × 1.35 保守估算，實際可能更久。
- **沒有儲存照片檔案**：回顧中的照片選項目前只記錄「這趟有拍照」標記。

## 第一次準備

1. Windows 安裝 [Node.js LTS](https://nodejs.org/)。
2. iPhone 到 App Store 安裝免費的 **Expo Go**。
3. 解壓縮本專案 ZIP，保留整個 `ExplorePathExpo` 資料夾。
4. Windows 電腦與 iPhone 連上同一個 Wi-Fi。

## 啟動方法（推薦）

進入 `ExplorePathExpo` 資料夾，雙擊：

`Start-ExplorePath.bat`

第一次會執行 `npm install`。看到 QR Code 後：

1. 保持 PowerShell 視窗開啟。
2. 用 iPhone 內建「相機」掃描 QR Code。
3. 點「在 Expo Go 中開啟」。
4. 進入 App 後保持「真實探索」，選時間與主題並搜尋。
5. iOS 詢問定位時選「使用 App 期間允許」。
6. iOS 詢問動態與健身時可允許；若拒絕，只會失去步數加成。

## PowerShell 指令

在檔案總管進入 `ExplorePathExpo` 資料夾，在網址列輸入 `powershell` 後按 Enter，再執行：

```powershell
npm install
npm start
```

如果 QR Code 連不上，在原視窗按 `Ctrl + C`，再執行：

```powershell
npm run start:tunnel
```

## 真機驗收建議

1. 真實模式選 20 分鐘與任一主題，允許定位。
2. 確認候選頁顯示大方向、直線距離、保守時間與 OSM 出處。
3. 開始後轉動 iPhone，確認指針會變化。
4. 切到其他 App 再回來，確認畫面先顯示背景暫停、之後恢復 GPS。
5. 使用「安全揭曉並開啟 Apple 地圖」，確認不會結束任務或扣除獎勵。
6. 回到 ExplorePath 後可換地點，已走步數與開始時間應保留。
7. 真正抵達後保持 App 在前景，停留 45 秒進入回顧。
8. 完成回顧後確認 XP、寵物與足跡；重新整理 Expo Go 後再確認資料仍在。
9. 切到 Demo 完成一次模擬探索，再切回真實模式，真實資料不得改變。

## 費用與資料來源

- Expo Go、Node.js、專案套件皆可免費使用。
- 地點搜尋使用 OpenStreetMap／Overpass 公開服務，沒有 API 金鑰、信用卡或自動付費備援。
- 公開服務可能限流或暫時失敗，App 只會清楚要求重試，不會切換成付費服務。
- 正式上架 App Store 日後仍會涉及 Apple Developer Program；目前 Expo Go 真機體驗不需要。

## 常見問題

- **離開檔案總管後 App 還能不能用？** 可以關閉檔案總管，但不能關閉提供 QR Code 的 PowerShell 視窗。
- **iPhone 沒跳定位權限？** 到「設定 → 隱私權與安全性 → 定位服務 → Expo Go」選擇「使用 App 期間」。
- **指南針方向不穩？** 在戶外遠離磁性配件，拿著 iPhone 畫 8 字校正；方向針只提供方位，不是道路導航。
- **沒有步數？** 到「設定 → 隱私權與安全性 → 動態與健身」允許 Expo Go；即使不允許，抵達 100 XP 仍正常。
- **PowerShell 出現紅色錯誤？** 把最後 20 行截圖提供給我。

- `npm run typecheck`：通過，使用 TypeScript 6。
- `npm run validate`：通過，版本、入口、相依檔案與回歸結構檢查。
- `npx expo install --check`：所有套件與 SDK 57 相符。

- iOS Hermes bundle：SDK 57 匯出成功，不等於真機啟動已驗證。
